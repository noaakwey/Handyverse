# 🚀 Солнечная система для малышей

Интерактивное 3D-приложение, которое знакомит ребёнка (примерно 4 лет) с
Солнечной системой. Управление простое и крупное, а все рассказы озвучиваются
по-русски — малышу не нужно уметь читать.

## ✨ Что внутри

- **Настоящая 3D-сцена** — Солнце и 8 планет в правильном порядке, со
  звёздным небом, кольцами Сатурна и подробной Луной у Земли.
- **Озвучка на русском** — нажми на планету, и приложение расскажет о ней
  голосом (Web Speech API).
- **Пояс астероидов** 🪨 — кольцо из сотен камней между Марсом и Юпитером.
- **Комета** ☄️ — летит по вытянутой орбите, у Солнца «отращивает» длинный
  хвост, который всегда направлен в сторону **от Солнца**.
- **Подробная Луна** 🌙 — кратеры, тёмные «моря» и кратеры с лучами; рельеф
  виден благодаря карте неровностей (bumpMap).
- **Космические явления** 🌗 (кнопка «Явления») — наглядные мини-сценки
  с объяснением «почему так бывает»:
  - **Фазы Луны** — почему Луна бывает то полной, то «месяцем»;
  - **Солнечное затмение** — Луна закрывает Солнце, её тень падает на Землю;
  - **Лунное затмение** — Земля закрывает Солнце, Луна краснеет.
- **Основы физики простыми словами:**
  - все планеты летают **вокруг Солнца** (Солнце их притягивает);
  - **близкие к Солнцу планеты летят быстрее** далёких (как в настоящей
    Солнечной системе);
  - комета у Солнца **разгоняется** и снова улетает далеко;
  - планеты **крутятся вокруг своей оси** — так получаются день и ночь;
  - у Земли есть **Луна**, которая кружится вокруг неё;
  - Уран **лежит на боку**, у Сатурна — **кольца**.
- **Крупные кнопки и понятные значки** для маленьких пальчиков.
- **Режим «Путешествие»** 🎬 — приложение само облетает все объекты по очереди.
- **Регулятор скорости** 🐢→🐇 и кнопка паузы.

## 🎮 Как пользоваться

| Кнопка | Что делает |
|--------|------------|
| 🏠 Вся система | Показать всю Солнечную систему целиком |
| ⏸️ / ▶️ | Остановить или запустить движение планет |
| 🎬 Путешествие | Облететь все объекты по очереди |
| 🌗 Явления | Показать фазы Луны и затмения с объяснением |
| 🔊 / 🔇 | Включить или выключить голос |
| 🐢——🐇 | Скорость движения планет |
| Планеты внизу | Быстро перелететь к нужной планете |

Ещё можно **крутить и приближать** космос пальцем или мышкой, а также
**нажимать прямо на планеты** в 3D.

## ▶️ Как запустить

Приложению нужен обычный веб-сервер (модули ES не работают по `file://`).

```bash
# Любой из вариантов, затем открыть http://localhost:8000
python3 -m http.server 8000
# или
npx serve
```

Затем откройте показанный адрес в браузере (Chrome, Safari, Edge или Firefox).

> Интернет не нужен: библиотека Three.js лежит в папке `vendor/`, а все
> текстуры планет рисуются прямо в браузере. Достаточно локального
> веб-сервера (из-за политики безопасности ES-модули не открываются по
> `file://`).

## 🌐 Публикация на GitHub Pages

Приложение полностью статическое, поэтому отлично работает на GitHub Pages.
В репозитории уже есть автоматический деплой
(`.github/workflows/deploy-pages.yml`). Workflow сам пытается **включить
Pages** (`enablement: true`), поэтому обычно достаточно просто сделать пуш.

Если у организации/аккаунта это запрещено политикой, включите Pages вручную
один раз:

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе **Build and deployment** → **Source** выберите **GitHub Actions**.
3. Перезапустите workflow: вкладка **Actions** → *Deploy to GitHub Pages* →
   **Re-run jobs** (или сделайте новый пуш).
4. Через минуту сайт будет доступен по адресу вида
   `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Готово — ссылку можно открывать на телефоне или планшете и показывать ребёнку.

## 🛠 Технологии

- [Three.js](https://threejs.org/) — 3D-графика (WebGL)
- Web Speech API — озвучка на русском языке
- Чистый HTML/CSS/JS, без сборки — открыл и работает

## 📁 Структура

```
index.html        — разметка и панели управления
css/styles.css    — оформление (крупный «детский» интерфейс)
js/data.js        — данные о планетах, комете, поясе астероидов и явлениях
js/textures.js    — процедурные текстуры (рисуются на canvas)
js/demos.js       — сценки явлений: фазы Луны и затмения
js/main.js        — 3D-сцена, физика движения, управление, озвучка
vendor/three/     — локальная копия библиотеки Three.js (r160)
```
